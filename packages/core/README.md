# @greenhat-services/magpie-core

Platform-neutral core of the Magpie JavaScript SDKs: events, stack parsing, scrubbing, scope, tracing and the client.

```sh
npm install @greenhat-services/magpie-core
```

You normally do not install this yourself. It is used by `@greenhat-services/magpie-browser` and `@greenhat-services/magpie-node`.

Full documentation, options and what is (and is not) sent: https://github.com/Greenhat-Services/magpie-js#readme
